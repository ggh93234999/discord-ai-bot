# Discord AI 機器人（大笨bot）

讀取頻道的歷史訊息當上下文，用本地模型（例如 Qwen，經 LiteLLM 的 OpenAI 相容 API）回覆。
機器人本體跑在 Linux 伺服器上（systemd 服務 `discord-bot`），連到你設定的模型 API（`LLM_BASE_URL`）。
Discord 機器人只需要「往外連」Discord，不用開任何連接埠。

## 快速開始（自己架一隻）

### 1. 需要什麼
- Python 3.11 以上
- 系統要裝 `ffmpeg`（放音樂用）和 `node`（yt-dlp 解 YouTube 用）。Ubuntu／Debian：`sudo apt install ffmpeg nodejs`
- 一個 **OpenAI 相容的模型 API**：本機的 Ollama、LiteLLM、vLLM，或 OpenAI、DeepSeek 等線上服務都行
- 一個 Discord 機器人帳號（下一步）

### 2. 建立 Discord 機器人並拿到 token
1. 到 [Discord Developer Portal](https://discord.com/developers/applications) → **New Application**，取名字。
2. 左邊 **Bot** 頁 → **Reset Token** → 複製出現的 token（只會顯示一次）。**這就是 `DISCORD_TOKEN`，等同機器人的密碼，不要貼到任何公開的地方。**
3. 同一頁往下找到 **Privileged Gateway Intents**，打開 **Message Content Intent**（沒開機器人讀不到訊息內容）。
4. 左邊 **General Information** 複製 **Application ID**（也就是 client id）。
5. 邀請機器人進你的伺服器：把下面「邀請連結」裡的 `YOUR_CLIENT_ID` 換成剛才的 Application ID，用瀏覽器打開、選伺服器、同意。

### 3. 安裝與設定
```bash
git clone https://github.com/ggh93234999/discord-ai-bot.git
cd discord-ai-bot
python3 -m venv .venv
source .venv/bin/activate          # Windows：.venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env               # Windows：copy .env.example .env
```
然後用文字編輯器打開 `.env`，**把金鑰填在這裡**（這個檔案已被 `.gitignore` 擋住，不會被 git 上傳；千萬不要把它傳給別人或貼到聊天室）：

| 變數 | 填什麼 |
|---|---|
| `DISCORD_TOKEN` | 上一步複製的機器人 token |
| `LLM_BASE_URL` | 模型 API 位址，要含 `/v1`。Ollama：`http://localhost:11434/v1`；LiteLLM：`http://localhost:4000/v1`；OpenAI：`https://api.openai.com/v1` |
| `LLM_API_KEY` | 模型 API 的金鑰。Ollama 不檢查，隨便填一個非空字串（例如 `ollama`）即可 |
| `LLM_MODEL` | 模型名稱，要跟 API 那邊的名稱一樣，例如 `qwen3:8b`、`gpt-4o-mini` |
| `DEEPSEEK_API_KEY` | 選填，只有想用 `/餘額` 查 DeepSeek 餘額才需要 |
| `ADMIN_USER_IDS` | 選填，除了機器人擁有者以外，還有誰能用 `/模型` 切模型（Discord 使用者 ID，逗號分隔） |

其他選填設定都有預設值，說明寫在 `.env.example` 裡。

### 4. 啟動
```bash
python bot.py
```
看到「已同步斜線指令」就成功了。到 Discord 打 `/` 就能看到指令（第一次可能要等一兩分鐘，或按 Ctrl+R 重新整理）。
語音和聊天都在這一個程式裡，**不需要對外開任何連接埠**，機器人只是主動連出去 Discord 和你的模型 API。

要長期運作的話，可以用 systemd：參考 `discord-bot.service.example`，改掉使用者和路徑後放到 `/etc/systemd/system/`，再 `sudo systemctl enable --now discord-bot`。

### 5. 常見問題
- **機器人在線上但不回話**：多半是 **Message Content Intent** 沒開（步驟 2-3），或 `LLM_BASE_URL` 連不到（看終端機的錯誤訊息）。
- **指令沒出現**：重新整理 Discord（Ctrl+R）；確認邀請連結有包含 `applications.commands`。
- **放音樂沒聲音／失敗**：確認系統有 `ffmpeg`，機器人有「連線」和「說話」權限；YouTube 常改版，`pip install -U yt-dlp` 通常就會好。
- **token 外洩了**：馬上回 Developer Portal 重新 **Reset Token**，舊的就失效，再把新的填進 `.env`。

## 什麼時候會回

- 私訊機器人
- 在頻道裡 @機器人，或直接回覆機器人的訊息
- 用 `/自動回覆 開` 開啟的頻道，任何人說話都回

其他機器人發的訊息一律不理，避免兩個機器人互相無限對話。
模型那台電腦關機或沒開模型時，機器人會回「模型那台電腦現在沒開或連不到」。

## 功能

- **看圖**：最近 4 則訊息裡的圖片（最多 4 張）會縮圖後一起送給模型。
- **天氣**：問天氣會用 Open-Meteo 查（免費、不用金鑰）。
- **上網**：需要即時資訊時，模型自己決定要不要用 DuckDuckGo 搜尋、打開網頁讀內容。
  查的時候會先出現「🔎 搜尋：…」，查完那則訊息會變成答案。
- **放音樂（YouTube）**：先進語音頻道，再用 `/播放 歌名或網址`，或直接說「@大笨bot 放周杰倫的晴天」「放點讀書的音樂」「下一首」。
  可以貼單首網址或整個播放清單（最多 50 首）。佇列播完 3 分鐘、或語音頻道沒人 1 分鐘，會自己離開。
  yt-dlp 建議定期更新（可參考 `update-ytdlp.sh.example` 設成每週的 crontab），YouTube 改版時通常更新就會好。
- **開頻道**（要叫它開的人本身要有「管理頻道」權限；機器人也要有「管理頻道」，臨時語音房再加「移動成員」）
  - `/開頻道 名稱 類型 [分類] [私人]`，或直接說「@大笨bot 幫我開一個叫 xxx 的語音頻道」
  - `/改頻道 [頻道] [新名稱] [分類]`：改名或搬到別的分類，也可以直接說「把大笨bot 語音頻道移到語音頻道分類」
  - `/關頻道 方式 [頻道] [隱藏]`：封存（鎖住、可還原）、解除封存、刪除（永久，會先跳確認按鈕）。
    用說的只能封存／解除封存，不能刪除。封存需要機器人另有「管理身分組」權限。
  - `/頻道狀態 [狀態] [頻道]`：設定語音頻道狀態（留空＝清除），也能直接說「把語音狀態改成 讀書中」。手動設定的狀態不會被歌名蓋掉。
  - `/臨時語音房 開`：建立「➕ 建立語音房」入口，有人進去就自動開一間他的房間並移過去，人走光自動刪掉
- **占卜**（`divination.py`）：直接聊天說「@大笨bot 幫我抽塔羅問工作」「幫我擲筊問明天面試好不好」「抽支籤問感情」「用易經卜一卦」就好，沒有斜線指令。
  - 種類：塔羅牌（78 張、正逆位；牌陣：單張、過去現在未來、二選一、感情）、擲筊（最多連擲 3 次，聖筊 1/2、笑筊 1/4、陰筊 1/4）、抽籤詩（天上聖母六十甲子籤，要擲到聖筊才算數，不然重抽）、易經（三錢法起卦，含變爻和之卦，依變爻數決定看卦辭或爻辭）。
  - 牌、籤、卦都由程式用系統亂數決定，結果卡由程式直接貼在回覆最上面，模型只負責解讀，不能自己編結果。
  - 籤詩和《周易》原文來自維基文庫，存在 `divination_data/`；塔羅牌義是自己整理的常見解釋。
  - 每種占卜都附圖（`drawimg.py`）：擲筊畫出每一擲兩個筊的平凸面、籤詩畫成直式籤紙、易經畫出本卦與之卦的卦象並標出變爻。
  - 塔羅會附上牌陣圖片（`drawimg.py` 用 Pillow 畫；牌面是 1909 年的偉特塔羅牌，公有領域，取自維基共享資源，存在 `divination_data/tarot/00.jpg`～`77.jpg`，編號同 `divination.TAROT`，逆位會倒過來畫）。
- **八字命盤／星盤**（`fortune.py`）：說「@大笨bot 幫我排八字和星盤，1990-05-15 14:30 台北出生，男」。資料不夠時機器人會先問。
  - 八字會附上五行配色的命盤圖（四柱、十神、藏干、納音、五行數量、大運），也是 `drawimg.py` 畫的。
  - 八字用 `lunar_python`（壽星萬年曆）：年柱、月柱看出生的絕對時刻（節氣交接準確），日柱、時柱用出生地真太陽時（經度＋均時差）；附十神、藏干、納音、五行數量，給性別會排大運。可輸入農曆生日（含閏月）。
  - 星盤用 `kerykeion`（Swiss Ephemeris，回歸黃道、普拉西度宮位）：行星落座、宮位、逆行、主要相位、元素分布，並畫成中文星盤圖附在回覆上（`svg2png.py` 用伺服器的 Chromium／playwright 把 SVG 轉 PNG，`SVG_PYTHON` 可指定要用哪個 Python）。沒有出生時間時用中午計算並提醒宮位、上升不準。
  - 出生地：台灣各縣市和常見城市內建經緯度與時區，其他地點用 Open-Meteo 地名搜尋，或由模型提供經緯度＋時區。
- **斜線指令**
  - `/播放 <歌曲>`、`/跳過`、`/暫停`、`/繼續`、`/停止`、`/佇列`、`/隨機`
  - 放歌時會在點歌的頻道貼一個**播放面板**：正在播放＋進度條（15 秒更新一次）、接下來的歌和總長度、播完會顯示「✅ 歌單播完了」，離開時顯示「👋 已離開」。面板被聊天洗上去時，換歌會自動重貼到最下面；`/佇列` 也能把它叫到最下面。按鈕：⏯️ 暫停/繼續、⏭️ 跳過、🔀 隨機、⏹️ 停止。
  - 放歌時語音頻道狀態會自動顯示「🎶 歌名」，播完或離開時還原。
  - `/插播 <歌曲> [立刻播]`（英文 `/playnext`）：插歌。預設插到「下一首」；「立刻播」選開就馬上播並跳過現在這首。也可以直接說「插一首周杰倫的晴天」，AI 會用 music 工具的 `position`（end／next／now）
  - `/移除 <編號或歌名>`：從佇列拿掉某一首；`/清空佇列`：接下來的全拿掉（現在這首放完）
  - `/歷史`：看播放紀錄（每首播過的歌自動記在 `play_history.json`）；`/隨機循環 開|關`：懶得選歌時，從紀錄隨機一直放，佇列空了自動補 5 首（避開最近播過的）；也可以直接跟機器人說「隨便放」
  - `/投票 <題目> <選項1> <選項2> [選項3~5] [分鐘]`：按鈕投票，每人一票可改票，時間到公布結果（重開機器人後進行中的投票會失效）；`/抽籤 <選項> [人數]`：從一串選項隨機抽；`/亂數 <最小> <最大> [數量] [不重複]`：隨機抽數字（也可以直接跟機器人說「8到80隨機一個」，他會呼叫 random_number 工具，不會自己編）；`/狀態`：看模型連線、延遲、啟動多久、有沒有在放歌（程式在 `extras.py`）
  - `/模型 [模型名稱]`：看或切換 AI 模型（只有機器人擁有者能切；切之前會先試打一次，選擇存在 state.json）。線上模型（如 deepseek）計費，內容陣列壓成純文字（圖片照送，deepseek 看得懂圖），不送 Ollama 專用參數（keep_alive），但仍會送 reasoning_effort（`REMOTE_REASONING_EFFORT`，預設 none，因為 DeepSeek 不帶參數會思考、多花 3~4 倍費用）；`.env` 可加 `ADMIN_USER_IDS`（逗號分隔）讓其他人也能切、`LOCAL_MODELS`（逗號分隔）標示哪些是本機模型。`/狀態` 會顯示今天和近 7 天各模型的呼叫次數與 token（程式在 `models.py`）
  - **中英指令共存**：每個中文指令都有一個英文名字的版本（例如 `/播放` = `/play`、`/投票` = `/poll`、`/亂數` = `/random`），做一樣的事；對照表在 `aliases.py` 的 `TABLE`，新增指令時記得在那裡加一行。`/help` 會顯示每個指令的英文名
  - `/餘額`：查 DeepSeek 帳戶剩多少錢（只有機器人擁有者能查，結果頻道裡大家看得到；需在 `.env` 加 `DEEPSEEK_API_KEY=`，用 DeepSeek 官方的 /user/balance 查）
  - `/help`：看所有指令
  - `/私訊紀錄 [使用者] [則數]`（英文 `/dmlog`）：機器人擁有者專用、只有自己看得到。不填使用者列出最近私訊過機器人的人（記在 `dm_users.json`），指定使用者就讀出他跟機器人的私訊（太長會變成附件）。只看得到傳給機器人的私訊，看不到使用者之間的私訊。`/help` 裡有註明私訊內容擁有者看得到。
  - `/總結 [則數] [重點]`：總結最近的對話（預設 100 則，最多 500）
  - `/重置`：讓機器人忘掉這個頻道到目前為止的對話
  - `/自動回覆 開|關`：這個頻道要不要每則都回（需要「管理頻道」權限）

## 調整

- **個性和說話方式**：改 `system_prompt.txt`，存檔後下一則回覆就生效，不用重開。
  （上網工具的使用規則和現在時間是程式自動加在後面的，不用寫在這裡。）
- **其他設定**在 `.env`，改完要 `sudo systemctl restart discord-bot`：
  - `HISTORY_LIMIT`：往回讀幾則訊息。越多越懂前後文，但模型處理越久。
  - `REASONING_EFFORT`：`none` 最快；想要它多想一下改 `low` / `medium` / `high`。
  - `MAX_TOKENS`：每次回覆長度上限。
  - `WEB_TOOLS=off`：關掉上網／天氣。
  - `IMAGE_LOOKBACK`、`MAX_IMAGES`、`IMAGE_MAX_SIDE`：看圖的範圍、張數、縮圖大小。

## 代幣系統（economy.py）
- 賺：每分鐘最多 +10 🪙——在文字頻道發言，或掛在語音頻道（沒關耳機、不在 AFK 頻道）。新玩家起始 200。資料在 `wallet.json`，每個伺服器各自一本帳。
- 賭博類斜線指令（`/賽馬` `/擲硬幣` `/骰子` `/老虎機` `/21點`）目前**暫時下架**，程式都還在：把 `economy.py` 的 `GAMBLING_ENABLED` 改成 `True` 再重啟機器人就會回來。同樣的遊戲仍可在 Discord Activity 裡玩（見下）。
- 指令：`/規則`(rules) `/錢包`(wallet) `/排行`(leaderboard) `/轉帳`(pay) `/擲硬幣`(coinflip) `/骰子`(dice) `/老虎機`(slots) `/21點`(blackjack)。
- 老虎機：單排 3 格用 🍒🍋💎 三種圖案，三個一樣 2~3.2 倍，兩個一樣退錢（理論回報率約 95%）；21 點 Blackjack 賠 1.5 倍；其餘賭局公平。
- 21 點開局先扣賭注，機器人若在牌局中重啟，該局賭注會損失。
- `/發錢 對象 金額`（give）：機器人擁有者專用，直接發代幣。
- `/老虎機 賭注 [格數]`：3 格（單排）、9 格（3×3，8 條連線）、16 格（4×4，整排整欄加兩條對角線共 10 條，4 格一樣才算，3 種圖案）。多格版可同時中很多條，3×3 只有 🍒🍋🔔💎 四種圖案（約 41% 的把數會賺錢，三個一樣 1.2~2.8 倍）。各版本理論回報率都調在約 95%。
- `/賽馬 [等待秒數]`（horserace）：開一場賽馬，6 匹馬從 10 匹固定名單隨機出賽，每匹有速度／耐力／爆發數值（存 `horses.json`）、當天狀態和歷史戰績（出賽、勝場、近 5 場名次）。賠率 = 0.95 ÷ 勝率，勝率由能力＋狀態算出，所以強馬賠少、冷門賠多。按按鈕選馬、填賭注；每人一注，截止後播放跑道動畫並結算。機器人在比賽中途重啟，這場的賭注會損失。

## Discord Activity 小遊戲（`activity/`）
在語音頻道打開的內嵌遊戲視窗（Discord Embedded App SDK），WebSocket 即時同步。選單分三類：
- **棋類（雙人）**：五子棋、四連棋、黑白棋、西洋棋（王車易位、吃過路兵、升變）、象棋（將死／困斃；尚未做長將判和）。可對賭代幣。
- **動作・競技**：小朋友下樓梯（1–4 人）、彈珠台（單人）、皮卡丘排球 2P、小朋友齊打交（最多 8 人）。皮卡丘與 LF2 的原版素材/程式不在 repo 內（見 `activity/.gitignore`）。
- **賭場**：老虎機（3 格／3×3／4×4）、德州撲克、台灣麻將、日本麻將、21 點、賽馬、骰子、擲硬幣，以及「旁觀大廳」。每個遊戲都有 📖 規則；可選練習幣或真代幣（賭注模式，背景會變紅色），右側有賭注紀錄。
- **觀戰**：所有雙人桌預設先進觀眾席（可在座位列選擇上場／離座），旁觀大廳可同步看別人的房間。皮卡丘排球有音量滑桿。

### 德州撲克
2–6 人，練習籌碼（起始 1000），可按空位加電腦玩家，其他人旁觀。發牌與判定全在伺服器（`activity/server/poker.js`）。
- 邊池、最小加注、25 秒行動時限（桌面中央有倒數計時，輪到自己整個背景變藍）、攤牌時列出所有未棄牌者的底牌與牌型並停留 11 秒；Q-K-A-2-3 不算順子，A-2-3-4-5 與 10-J-Q-K-A 算。
- 加注可拉桿、½池／1池／全下，也可直接輸入自訂金額。牌用四色（黑桃黑、紅心紅、方塊藍、梅花綠）。
- 先入座再開打：有 2 人（含電腦）以上入座後，任一位入座的人按「▶ 開始」才發第一手，之後自動連續；人數掉到不足 2 人就停下，要再按開始。
- 可自訂名稱（記在瀏覽器）、🔄 重開（兩段確認，大家籌碼回起始值）。
- **盲注**：預設固定 10/20；可在「⚙ 盲注設定」改起始小盲（大盲 = 2 倍），並可選擇「隨手數升盲」（每 N 手升一級，順序 …10→15→20→30→50→75→100→150→200…）。從下一手起生效。
- **電腦**：用蒙地卡羅算勝率＋底池賠率決定動作，每個名字有不同個性（愛衝、穩健、老狐狸、跟注機、超緊、心機、全下狂、新手；畫面只顯示「？」）。加入順序隨機；電腦輸光會換成新電腦（盡量不重複）。

### 鍛造（Activity 版）
獨立玩法（不是賭博，不寫入賭博紀錄、不列在旁觀大廳）：把一把劍鍛到最高 100 階（10 種材質 × 10 級，每一階都有程式畫的 SVG 外觀，越高階越華麗；神劍有旋轉光環）。每次鍛造要付鍛造費，有機率成功或劍碎（整把歸零）；每階有賣價，隨時可賣。
- 每個身分（練習幣／真代幣各自）最多同時擁有 10 把劍，上方 1~10 號格子可以切換要鍛造或賣掉哪一把；舊的單把存檔會自動放進 1 號。
- 鍛造身分組（真代幣模式）：手上每把劍所在區間各對應一個 Discord 身分組——30 鑄劍學徒、40 百煉匠、50 鑄劍師、60 名匠、70 劍宗、80 劍聖、90 劍仙、100 神鑄；持有幾個不同區間的劍就有幾個身分（同區間多把只算一個），劍碎或賣掉後沒有該區間的劍了，身分就移除；低於 30 階沒有身分。身分組由機器人建立（需要「管理身分組」權限，且機器人的身分組要排在這些之上），活動後端透過內部 API `/forge/role` 通知機器人。
- 鍛造音效：用 Web Audio 即時合成（不需要音檔）——開始鍛造的兩下敲鐵砧、成功的鈴聲（階數越高越亮，50 階以上多一串閃光）、失敗的悶響加玻璃碎裂、卷軸擋下的閃光和弦、賣劍的金幣聲。畫面左上角的 🔊 可以開關，設定記在這個瀏覽器。
- 神兵榜：活動選單「鍛造」那一類裡有「🏆 神兵榜」，分賭注模式（真代幣）和練習模式兩張榜，依每個人目前手上最高階的劍排名（前 30 名，每 10 秒更新），顯示名字、階數、劍名、擁有幾把、賣價。名字有登入 Discord 才知道，沒登入的練習玩家顯示「匿名鍛造師」。
- 防止破壞卷：劍 30 階以上才會出現，在鍛造按鈕上方勾選「防止破壞卷」，這次鍛造多付一份卷軸費，失敗時劍不會碎、留在原階（成功照樣升階）；可無限次使用，練習幣和真代幣都能用。卷軸價為「失敗平均損失×1.15」與「6×成功率×賣價增加−鍛造費」取大，所以每步都用卷軸衝的期望回收率只有約 1/6。價格表在 forge.js 的 SC。
- 數字在 `activity/server/forge.js`：第 1 階約 47、第 50 階約 1.26 萬、第 70 階約 10.8 萬、第 90 階約 121 萬、第 100 階約 448 萬（真代幣賣出沒有上限）；成功率前 49 階 97.3%→94.3%、50 階起 94%→91%；從零全部成功鍛到 100 階共花 100 萬，全部成功的機率：10 階約 74%、30 階約 33%、50 階約 12%、100 階約 0.23%。第 3 階起賣掉就賺；每一步的期望回收率：1~49 階約 103%、50 階以後約 101%，所以鍛造越久期望淨值越高（從零衝到 50 階再賣約 +530、70 階約 +950、100 階約 +2,600）。鍛造在活動選單最上面，獨立成一類。
- 練習幣與賭注模式（真代幣）各存各的劍，存在 `activity/server/forge.json`（已 `.gitignore`）：練習模式用瀏覽器識別碼，賭注模式用 Discord 身分。真代幣的費用和賣出走機器人錢包，中途重啟由 escrow 退回／補發；真代幣的鍛造費超過單筆上限時分筆扣款。練習模式起始 10 萬練習幣。

### 麻將（台灣 16 張／日本立直）
賭場裡兩張獨立的牌桌，4 人一桌、練習點數（不碰代幣），每個 Activity instance 各一桌。流程共用 `activity/server/mahjong.js`，牌的編碼／向聽數／拆牌在 `mjcore.js`，計分在 `mjtw.js`（台數）和 `mjjp.js`（役、符、翻、點數）；前端是 `activity/src/mahjong.js`。
- 先入座、可按空位「＋電腦」，任一位入座的人按「▶ 開始」開打（空位自動補電腦）。打到一半離座或斷線由電腦代打；沒入座的人可以點電腦的位置接手（保留點數）。所有真人都走了牌桌就重置。
- 台灣麻將：16 張、花牌自動補花、吃碰槓、搶槓、0 台可胡；底／台可選（30/10～1000/300），一圈或一將。莊家 1 台、連 N 拉 N 加 2N 台（莊家胡或莊家付錢時才算）；留 16 張流局、莊家連莊。八張花直接八仙過海。
- 日本麻將：13 張，一定要有役才能胡；立直（含雙立直、一發、裏寶牌）、槓寶牌、嶺上、振聽（含同巡與立直後振聽）、流局聽牌料、本場、立直棒；東風戰或半莊戰，被擊飛就結束。有赤寶牌（萬筒條的 5 各一張紅色，每張 +1 翻，開局可關；牌用 100+牌種 表示，`mjcore.kindOf` 換回牌種）、雙倍役滿不另計、一炮多響只算順位最近的一家。
- 電腦：用向聽數＋進張數決定打哪張；日麻聽牌就立直、只在有役牌時才副露，有人立直時優先打現物；台麻能讓向聽數變少就吃碰。
- 滑鼠指到手牌（手機長按）會顯示這種牌場上看得到幾張、還剩幾張沒出現、誰打的、誰副露了，桌上同樣的牌用藍框標出來。日麻的寶牌會金色發光，赤寶牌是紅框。
- 輪到自己打牌時整個背景變藍色，可以吃碰槓胡時變橘色。
- 時限：輪到自己 20 秒（超時打出摸到的牌，能自摸就自摸），叫牌 9 秒（超時算過）。
- 測試：`mahjong.js` 有 `_simGame(rule, cfg, greedy)` 可以讓 4 個電腦直接打完一整場（greedy 會什麼都叫、能槓就槓），用來檢查點數守恆和罕見流程。

### 一起看影片（Activity）
遊戲間「🎬 影音」裡的「📺 一起看影片」：同一個 Activity 的人同步看 YouTube。後端 `activity/server/theater.js`，前端 `activity/src/theater.js`。
- 貼 YouTube 連結（watch、youtu.be、shorts 都可以）或直接打關鍵字（搜尋第一個結果）加入清單；清單可移除、移到下一部、跳過。直播和超過 3 小時的影片不收。
- 伺服器用 yt-dlp 把影片下載成 720p H.264＋AAC 的 mp4（`video_cache/`，已 `.gitignore`，超過 30 GB 自動刪最久沒看的），從 `/api/tv/<影片ID>.mp4` 串流（支援 Range，可以拖進度）。下載好才開始播，清單接下來兩部會先下載。
- 播放／暫停／拖進度／換片由伺服器統一記錄，每 5 秒推一次狀態，前端誤差超過 1～1.5 秒就自動跳過去校正。音量、靜音、全螢幕各自調。
- 畫質每個人自己選（360p／480p／720p／1080p，依影片有的 H.264 畫質）：房間預設下載 720p；有人選別的畫質時伺服器才另外下載（`<影片ID>.q1080.mp4` 這類檔名，也算在快取上限裡），準備好就從同一秒切過去，選擇記在瀏覽器。1080p 每人約 4～8 Mbps。
- 播放速度（0.5～2 倍）大家一起變；字幕每個人自己選：只用 YouTube 影片本身的字幕（上傳者提供的＋YouTube 依原語言自動產生的），第一次選時才下載（`/api/tv/sub/<影片ID>/<語言>.vtt`，還在下載時回 202、前端每 3 秒再問），簡體中文字幕會在本機用 OpenCC 轉成繁體。不用 YouTube 的「自動翻譯」字幕（常被限流 429），也不用 AI 翻譯。
- 全螢幕：先試瀏覽器原生全螢幕，不行就鋪滿活動視窗（控制列 2.5 秒自動隱藏、雙擊或 Esc 切換）。在 Discord 裡另有 🌐「在瀏覽器開啟」，用 `openExternalLink` 開 `…/wordle/?room=<同一個房間>&g=theater`，跟 Discord 裡的人同步，瀏覽器可以真正全螢幕。網址帶 `?g=遊戲代號` 會直接開那個遊戲。
- 瀏覽器規定沒按過畫面不能自動放聲音，被擋時會出現「🔊 點一下開始播放」。
- 每個觀眾都是從家裡的伺服器拿影片（720p 約 2～4 Mbps／人），人多時注意家裡網路的上傳頻寬。

### 賽馬（Activity 版）
所有人共用同一場；伺服器決定名次、每人畫面一致。10 匹馬的能力值、出賽、勝場、近 5 場存在 `activity/server/horses.json`（所有人共用，已 `.gitignore`；初始以 1000 場模擬當基本資料）。每匹有跑法（先行／逃馬／追込／穩定／爆發）和毛色，會影響動畫。下注頁每匹馬顯示戰鬥卡：能力雷達圖、歷史戰績、近 5 場、當天狀態、倍率；**不顯示本場勝率**，要自己判斷。

### 部署
- 前端：`activity/`（Vite 打包，`npm install && npm run build`，產物在 `activity/dist/`；前端改動只需重新 build）。把 `VITE_CLIENT_ID` 寫進 `activity/.env`（Application ID，不是密鑰）。
- 後端：`activity/server/`（Node + ws，預設 `127.0.0.1:3101`，用 `node server.js` 或 systemd 常駐；後端改動需重啟）。賭場／撲克／賽馬紀錄等執行時資料（`horses.json`、`casino_log.json`、`escrow.json`…）都在這裡，不進 git。
- 對外：需要公開 HTTPS 網址。Developer Portal → Activities → URL Mappings 把 `/` 指到你放 `dist/` 的目錄；WebSocket 路徑 `/ws` 要轉到後端（Apache 用 `ProxyPass /你的路徑/ws http://127.0.0.1:3101/ws upgrade=websocket`）。
- 機器人端：Discord 開啟 Activities 後會自動建立入口指令 `/launch`；整批同步指令時必須把它一起帶上（`bot.py` 的 `sync_commands` 已處理）。
- 沒發佈的 Activity 只有擁有者和開發團隊成員能開。
